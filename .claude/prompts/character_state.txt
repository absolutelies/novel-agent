## State Structure (English)

```
[English Character Name]:

├── ITEMS:
│   ├── [English item]: [English description, condition, significance]
│   ├── [English item]: [English description]
│   └── [English item]: [English description]

├── ABILITIES:
│   ├── [English skill]: [English capability description]
│   ├── [English skill]: [English capability description]
│   └── [English limitation]: [English what they cannot do]

├── STATUS:
│   ├── Physical: [English body state - injuries, fitness, appearance]
│   ├── Mental: [English psychological state - mood, stability]
│   ├── Social: [English reputation and relationships]
│   └── Resources: [English assets, wealth, access]

├── RELATIONSHIPS:
│   ├── [English name]: [English relationship state - nature, tension, change]
│   ├── [English name]: [English different relationship dynamic]
│   └── [English name]: [English relationship state]

├── TRIGGERED EVENTS:
│   ├── [English event]: [English what affected them, consequence]
│   ├── [English event]: [English consequence]
│   └── [English event]: [English consequence]

├── CURRENT GOALS:
│   ├── Immediate: [English current pursuit]
│   ├── Short-term: [English next chapters goal]
│   └── Hidden: [English secret motivation]
```

---

## Tree Format (Western Standard)

Use these symbols exactly:
- `├──` for items in list
- `│   ├──` for nested items
- `└──` for final item in list
- Space after symbols for text

---

## Update Rules (English)

**For existing character state updates**:

1. **Items**: Add acquired, remove lost, update condition
2. **Abilities**: Add learned, note degraded, track costs
3. **Physical/Mental**: Reflect chapter events
4. **Relationships**: Update based on interactions
5. **Triggered Events**: Add new affecting events
6. **Goals**: Update if motivation changed
