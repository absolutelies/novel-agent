## R13: Perfect → Natural Dialogue

**AI Dialogue Problems**:
| AI Problem | Human Fix |
|------------|-----------|
| Grammatically perfect sentences | Add fragments, run-ons |
| Complete sentences always | Trail off, interrupt, restart |
| No conversational fillers | Add "um", "well", "you know" |
| All characters sound similar | Apply distinct voice per character |
| Exposition in dialogue | DELETE — characters don't explain to each other |
| Polite, measured responses | Make messier, emotional |
| Question-Answer pattern | Mix up, avoid direct Q&A |
| Balanced exchanges | Vary speech lengths |

**Natural Dialogue Examples**:
```
AI: "I understand your concern. Let me explain why this is necessary."
→ Human: "I know. Look—it's the only way."

AI: "That's a fascinating point you've made. I hadn't considered it from that perspective."
→ Human: "Huh. Didn't think of that."

AI: "I'm sorry, but I disagree with your assessment of the situation."
→ Human: "No. You're wrong."

AI: "What do you think we should do about this problem?"
→ Human: "So what do we do?" OR: "What now?"
```

## R14: Direct → Subtext

**AI tends to be direct. Humans use subtext.**

| Direct AI | Subtext Human |
|-----------|---------------|
| "I'm angry at you." | "I need some space." |
| "I love you." | [action: takes hand] |
| "I don't trust him." | "Keep your distance from him." |
| "I'm worried." | "Have we thought through all the angles?" |
| "I want to leave." | "I think I should head out." |
| "That hurt me." | "That was unnecessary." |
| "You're important to me." | "I don't want to lose you." |
| "I'm scared." | "I need a drink." |

**Rule**: If character directly states emotion → rewrite as action, gesture, or indirect statement.

---

## R15: Speech Length = Power

**Power Dynamics in Dialogue**:
| Character Position | Speech Pattern |
|--------------------|----------------|
| Dominant | Longer speeches, fewer breaks |
| Submissive | Short responses, hesitation |
| Conflict | Competition for speech time |
| Comfortable | Flowing exchanges |
| Tension | Interrupted, fragments |

**Questions = Control**:
- Who asks questions controls conversation
- Dominant: asks questions
- Submissive: answers questions
- Power shift: when answerer starts asking

## R16: Conversational Imperfections

**Add natural speech features**:

| Feature | Example |
|---------|---------|
| Interruption | "Wait, before you—" |
| Trail off | "I just... I don't..." |
| Restart | "I mean, what I'm saying is..." |
| Fillers | "Um", "well", "look", "I mean" |
| Fragment | "Not happening." / "Done." |
| Overlap | [two characters speaking simultaneously] |
