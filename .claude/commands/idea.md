# /idea - Story Idea Generation (English Only)

> Generate story concepts through web research on Western websites.

## CRITICAL: English Only

1. **Search only Western websites** (US/EU based)
2. **All output must be English**
3. **No Chinese sources or content**

---

## Usage

```bash
/idea "<genre/theme>"                — Generate 3-5 English concepts
/idea --select N                     — Select concept N
```

---

## WebSearch Configuration

**Allowed domains** (Western sources):
- reddit.com (r/writing, r/fantasy, r/scifi, etc.)
- medium.com
- goodreads.com
- archiveofourown.org
- wattpad.com
- royalroad.com
- scribblehub.com
- github.com
- tumblr.com

**Blocked domains** (Chinese sources):
- *.cn, *.tw, *.hk
- baidu.com, weibo.com, zhihu.com, douban.com

**Search region**: US

---

## Process

### Step 1: Web Research

Search Western websites:

```
"{genre} writing tips"
"{genre} tropes reddit"
"{genre} plot ideas Western fiction"
"{genre} successful novels analysis"
"{genre} character archetypes English fiction"
```

Extract from results:
- Western genre conventions
- Popular tropes in English fiction
- Recent successful Western novels
- Reader expectations (Western audiences)

### Step 2: Concept Generation

Combine research with user theme:
- Use Western naming conventions
- Western cultural context
- English idioms and expressions
- Western fiction structures

Each concept includes:
- **One-line essence** (Snowflake formula, English)
- **Hook**: Compelling element for Western readers
- **Conflict**: Primary tension
- **Unique angle**: What distinguishes it
- **Potential**: Expansion possibilities

### Step 3: Save Selected

Save to `memory/core_seed.md` (English only).
